# Data Structure and Graph Performance Analyzer

## Project Description

This project is a Java console-based application developed to demonstrate and analyze different data structures, searching algorithms, and graph traversal algorithms.

The system allows users to perform operations on arrays, stacks, queues, linked lists, and graphs. It also compares the performance of Linear Search and Binary Search, as well as BFS and DFS graph traversal.

## Main Features

- Array insertion, deletion, searching and display
- Stack push, pop, peek and display
- Queue enqueue, dequeue, peek and display
- Linked List insertion, deletion, searching and display
- Linear Search
- Binary Search
- Graph vertex and edge operations
- BFS traversal
- DFS traversal
- Searching performance comparison
- Graph traversal performance comparison
- Console-based menu system

## How to Run

1. Clone or download the GitHub repository.
2. Open the project in Eclipse IDE.
3. Make sure the Java environment is configured.
4. Run `Main.java`.
5. Use the console menu to select the required operation.

## Algorithms and Complexity

### Searching
- Linear Search: O(n)
- Binary Search: O(log n)

### Graph Traversal
- BFS: O(V + E)
- DFS: O(V + E)

## Performance Analysis

The application records the number of steps and execution time for searching and graph traversal operations. It also displays the search/traversal results and their time complexity.

## Validation and Error Handling

The application handles empty data structures and invalid operations such as attempting to pop from an empty stack, dequeue from an empty queue, delete from an empty linked list, or traverse a non-existing graph vertex.
